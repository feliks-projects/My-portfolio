**FELIKS-PROJECTS — Python Task Manager**

This is a small Python project created as a debugging example

**Project files**

Python version with bugs — original version containing several intentional errors
Fixed Python version — corrected and improved version of the Python script

**What was demonstrated**

- Finding syntax and logical errors
- Fixing filtering logic
- Handling empty data
- Input validation
- Error handling
- Working with lists and dictionaries
- Using functions
- Generating task statistics

**Technologies**

- Python 3
- Standard Python library

**Purpose**

This project demonstrates a simple debugging workflow: identifying problems in an existing Python script and creating a corrected version
